features:
  - icon: 💡
    title: From an idea to an app
    details: Describe what you want and let an agent build it, as a desktop app, an Android and iOS app, or both. The framework decides where each piece of code goes, so the agent spends its effort on the idea.
  - icon: 🤖
    title: The right code from AI agents
    details: The agent writes, runs one test, and reads what to move where. The rules turn "follow our architecture" into a check it can pass, so the app keeps its shape as it grows.
  - icon: ✅
    title: Rules you can run
    details: The UI layout, state, repositories, module dependencies, Koin and text are checked by one test in your own suite. A failure names the file and says how to fix it.
  - icon: 🧩
    title: One shape for every screen
    details: Sections and components take data and callbacks, and one place binds each ViewModel. The library has the pieces the rules expect, so the right structure is also the easy one.
  - icon: 🪟
    title: Desktop and mobile, each its own product
    details: A desktop window shows many panels at once, and a Container carries messages between them. A phone shows one screen with one ViewModel. The two share their domain and data, not their screens.
  - icon: 🛠️
    title: Built on Compose Multiplatform
    details: Kotlin and Compose throughout, on the JVM for the desktop and on Android and iOS for mobile. MVI with State, Action and Event keeps state one-way on every platform.
